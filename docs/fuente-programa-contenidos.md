## Notas de conversión

- **Origen:** la fuente primaria fue una captura de pantalla, no un PDF. Para asegurar fidelidad del texto y recuperar el hipervínculo, el contenido se contrastó contra la página en vivo `https://tadp-utn-frba.github.io/contenidos/`; ambos coinciden ítem por ítem.
- **Hipervínculo:** en la captura, la palabra "aquí" aparece subrayada pero la URL no es visible en la imagen. La dirección de destino se tomó de la página en vivo y se transcribe inline completa.
- **Estructura:** el original es una lista de viñetas anidada en dos niveles (viñeta sólida para las unidades, viñeta hueca para los temas). Se replica con listas Markdown anidadas; el estilo de viñeta no se conserva porque Markdown no lo distingue.
